# AluraBooks

Landing page responsiva inspirada em uma plataforma de venda de livros, desenvolvida com **HTML5** e **CSS3**, com foco em **responsividade**, **estrutura semântica**, **layout mobile-first** e adaptação para diferentes tamanhos de tela.

O projeto simula uma página inicial de e-commerce com menu de navegação, barra de pesquisa, carrosséis de livros, seção de tópicos, área de contato e rodapé completo.

## Tecnologias utilizadas

- HTML5
- CSS3
- Swiper.js
- Google Fonts

## Conceitos praticados

- Estruturação semântica com HTML5
- Estilização com CSS3
- Layout responsivo utilizando Flexbox
- Responsividade com `@media`
- Abordagem mobile-first
- Menu hambúrguer com HTML e CSS
- Uso de variáveis CSS com `:root`
- Integração de biblioteca externa para carrossel com Swiper.js

## Funcionalidades

- Menu de navegação responsivo
- Menu hambúrguer para dispositivos móveis
- Barra de pesquisa estilizada
- Carrosséis interativos de livros
- Cards de destaque de produtos e autora
- Seção de tópicos visitados recentemente
- Área de cadastro de e-mail
- Rodapé com links institucionais
- Layout adaptado para mobile, tablet e desktop

## Como executar o projeto

1. Clone ou baixe este repositório  
2. Abra o arquivo `index.html` no navegador  

Ou, se preferir, utilize a extensão **Live Server** no VS Code para rodar o projeto localmente.

## Objetivo do projeto

Praticar desenvolvimento de interfaces web com **HTML e CSS**, aplicando conceitos de responsividade, organização visual, componentes reutilizáveis e adaptação de layout para diferentes dispositivos.

## Aprendizados com o projeto

Durante o desenvolvimento deste projeto foram praticados conceitos importantes de front-end, como:

- construção de páginas responsivas
- organização de estilos em arquivo dedicado
- uso de variáveis CSS para padronização visual
- criação de menu mobile sem JavaScript
- integração com biblioteca externa para carrossel
- adaptação de layout para diferentes breakpoints
